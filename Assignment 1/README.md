# Assignment 1 — MNIST Preprocessing and CNN

Practical 1 demonstrates TensorFlow/Keras setup and preprocessing of the MNIST handwritten-digit dataset. The notebook normalizes images, reshapes them for convolution, visualizes sample digits, and defines a CNN with TensorFlow's low-level API.

## Files

- `DL_Prac1.ipynb` — executable notebook containing the MNIST workflow and CNN implementation.
- `DL_Assignment-1_12414973.docx` — editable practical implementation sheet/report.
- `DL_Assignment-1_12414973.pdf` — PDF export of the practical report.

## Requirements

TensorFlow, NumPy, and Matplotlib. MNIST is downloaded automatically by `tf.keras.datasets.mnist`.
