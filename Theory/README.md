- `Tensorflow and Keras - 1.pdf` — TensorFlow and Keras notes.

`Reference-01.pdf` through `Reference-06.pdf` are additional reference PDFs. Their original autogenerated filenames were shortened to make the files usable with Git on Windows. The numbered `.jpg` files are additional reference images.
