# Assignment 3 — Forward and Backpropagation Experiment

Practical 3 trains a dense neural network on MNIST using TensorFlow/Keras. It compares learning rates (`0.1`, `0.01`, and `0.001`) and epoch counts (5 and 10), then plots training loss for each run.

## Files

- `DL_Prac3.ipynb` — notebook with the MNIST experiment and loss comparison plot.
- `DL_Assignment-3_12414973.docx` — editable practical implementation sheet/report.
- `DL_Assignment-3_12414973.pdf` — PDF export of the practical report.

## Requirements

TensorFlow/Keras, NumPy, and Matplotlib. MNIST is downloaded automatically by Keras.
