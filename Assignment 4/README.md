# Assignment 4 — LSTM Sales Forecasting

This practical uses an LSTM to make one-step-ahead forecasts from a synthetic daily sales series. The report and notebook generate sales data with trend, seasonal patterns, promotions, and noise; turn it into 30-day input windows; and compare the model's forecasts with a previous-day baseline using MAE and RMSE.

## Files

- `DL_Assignment-4_12414973.docx` — practical implementation sheet containing the problem statement, code, and output.
- `Assignment4.ipynb` — executable sales-forecasting notebook.

There is no bundled dataset file because the code generates its own sales data. Dependencies include TensorFlow/Keras, NumPy, pandas, Matplotlib, and scikit-learn.
