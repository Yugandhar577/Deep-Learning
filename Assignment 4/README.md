# Assignment 4 — LSTM Sales Forecasting

This practical uses an LSTM to make one-step-ahead forecasts from a synthetic daily sales series. The report generates sales data with trend, seasonal patterns, promotions, and noise; turns it into 30-day input windows; and compares the model's forecasts with a previous-day baseline using MAE and RMSE.

## Files

- `DL_Assignment-4_12414973.docx` — practical implementation sheet containing the problem statement, code, and output.

There is currently no separate notebook or dataset file in this folder. The code in the report generates its own sample data. It uses TensorFlow/Keras, NumPy, pandas, Matplotlib, and scikit-learn.
