# Assignment 2 — Iris Classification with an MLP

Practical 2 builds and evaluates a multilayer perceptron for classifying the Iris dataset. It uses a stratified train/test split, feature standardization, and a Keras model with two hidden layers.

## Files

- `Assignment2.ipynb` — notebook that trains the MLP for 100 epochs and evaluates classification performance.
- `DL_Assignment-2_12414973.docx` — editable practical implementation sheet/report.
- `DL_Assignment-2_12414973.pdf` — PDF export of the practical report.

## Requirements

TensorFlow/Keras, NumPy, pandas, and scikit-learn. The Iris data is loaded from scikit-learn, so no separate dataset file is needed.
