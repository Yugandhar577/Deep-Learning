# Assignment 7 — Credit Default Classification

This notebook compares support-vector machine (SVM) and k-nearest-neighbors (KNN) classifiers for predicting credit-card payment default. It preprocesses selected credit and repayment features, evaluates multiple models, and generates confusion matrices, an accuracy chart, and a metrics heatmap.

## Files

- `Assignment7.ipynb` — complete analysis notebook.

## Requirements and data

The notebook uses pandas, NumPy, Matplotlib, seaborn, and scikit-learn. It expects the UCI credit-card dataset as `UCI_Credit_Card.csv`; update the input path in the notebook if it is not located at `/content/sample_data/`.
