## Running notebooks

The notebooks are intended for Jupyter/Google Colab. Install the libraries listed in each assignment README. Some notebooks download datasets or pretrained models, and Assignment 7's credit-default notebook expects `UCI_Credit_Card.csv` at its configured path.
