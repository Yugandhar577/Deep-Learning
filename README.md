## Reference material

- `Tensorflow and Keras - 1.pdf` — TensorFlow and Keras reference material.

## Running notebooks

The notebooks are intended for Jupyter/Google Colab. Install the libraries used by the relevant notebook, such as TensorFlow, NumPy, Matplotlib, pandas, scikit-learn, and seaborn. Assignment 7 additionally expects `UCI_Credit_Card.csv` at the path configured in its notebook.
