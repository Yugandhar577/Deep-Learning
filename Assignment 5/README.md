# Assignment 5 — RNN, LSTM, and GRU Comparison

This practical compares SimpleRNN, LSTM, and GRU models for binary sentiment classification of IMDB movie reviews. The report describes sequence padding, training three Keras models, and comparing accuracy, precision, recall, F1 score, confusion matrices, training time, and model size.

## Files

- `DL_Assignment-5_12414973.docx` — practical implementation sheet with the algorithm, code, and results.
- `Assignment_5_DL.ipynb` — executable model-training and comparison notebook.

The notebook uses TensorFlow/Keras, NumPy, pandas, Matplotlib, and scikit-learn. The IMDB dataset is loaded through Keras.
